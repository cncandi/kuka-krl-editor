KUKA Programmierung lernen — KRL Einsteiger-Guide

Die KUKA Robot Language (KRL) ist die Programmiersprache aller KUKA-Industrieroboter. Dieser Guide erklärt die Grundlagen — von der ersten DEF-Zeile bis zu komplexen Bewegungssequenzen.

Programmaufbau: SRC und DAT

Jedes KRL-Programm besteht aus zwei Dateien:

  • Meinprogramm.src — der Programmcode
  • Meinprogramm.dat — die Datenliste (Positionen, Variablen)

Minimales Programm

&ACCESS RVP
&REL 1

DEF MeinErstesProgram()

   PTP {A1 0.0,A2 -90.0,A3 90.0,A4 0.0,A5 0.0,A6 0.0}

END

Bewegungsbefehle

PTP — Point-to-Point

Schnellste Bewegung von A nach B — der Roboter wählt den optimalen Weg selbst. Keine Garantie für einen geraden Pfad.

PTP P1            ; Achsinterpoliert
PTP P1 C_PTP      ; Mit Überschleifen

LIN — Lineare Bewegung

Der TCP (Werkzeugmittelpunkt) fährt exakt geradlinig. Für Schweißnähte, Kleberaupen oder genaue Positionierung.

LIN P2            ; Geradlinig
LIN P2 C_DIS      ; Überschleifen mit Abstand

CIRC — Kreisbewegung

Kreisbahn über einen Hilfspunkt:

CIRC P_Via, P_End         ; Kreisbogen
SCIRC P_Via, P_End, CA 90 ; 90° Bogen

Variablen deklarieren

DECL REAL  rGeschwindigkeit = 0.5
DECL INT   nZaehler         = 0
DECL BOOL  bBereit          = FALSE
DECL E6POS pHome

Ablaufsteuerung

IF-THEN-ELSE

IF $IN[1] == TRUE THEN
   PTP P_Gut
ELSE
   PTP P_Schlecht
ENDIF

FOR-Schleife

FOR i = 1 TO 10
   LIN P_Array[i]
ENDFOR

LOOP (Endlosschleife)

LOOP
   WAIT FOR $IN[1]    ; Auf Signal warten
   PTP P1
   PTP P2
ENDLOOP

E/A-Signale

$OUT[1]  = TRUE       ; Digitalausgang setzen
$OUT[1]  = FALSE      ; Digitalausgang rücksetzen
WAIT FOR $IN[1]       ; Warten auf Digitaleingang
$ANOUT[1] = 5.0       ; Analogausgang 5V

Geschwindigkeit und Werkzeug

$TOOL   = TOOL_DATA[1]  ; Werkzeug setzen
$BASE   = BASE_DATA[1]  ; Koordinatensystem
$VEL.CP = 0.3           ; 300 mm/s kartesisch
$ACC.CP = 1.0           ; Beschleunigung
