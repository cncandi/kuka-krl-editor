SRC und DAT Dateien bearbeiten — KUKA Programmdateien erklärt

Jedes KUKA-Roboterprogramm besteht aus zwei Dateien: der .src-Datei (Programm-Code) und der .dat-Datei (Datenliste). Wer diese Dateien professionell bearbeiten möchte, braucht die richtigen Werkzeuge.

Was ist eine .src Datei?

Die SRC-Datei (Source) enthält den eigentlichen KRL-Programmcode:

&ACCESS RVP
&REL 1
DEF MeinProgramm()

   $TOOL = TOOL_DATA[1]
   $BASE = BASE_DATA[1]
   $VEL.CP = 0.3

   PTP P1
   LIN P2
   LIN P3

END

Sie definiert den Programmablauf: Bewegungsbefehle (PTP, LIN, CIRC), Ausgänge, Wartezeiten und Unterprogrammaufrufe.

Was ist eine .dat Datei?

Die DAT-Datei (Data) enthält alle Positionsdaten und globalen Variablen:

&ACCESS RVP
DEFDAT MeinProgramm

   DECL E6POS P1={X 500.0,Y 0.0,Z 300.0,A 0.0,B 90.0,C 0.0}
   DECL E6POS P2={X 600.0,Y 100.0,Z 300.0,A 0.0,B 90.0,C 0.0}
   DECL E6POS P3={X 700.0,Y 0.0,Z 300.0,A 0.0,B 90.0,C 0.0}
   DECL REAL rGeschwindigkeit

ENDDAT

SRC und DAT Dateien bearbeiten — die besten Methoden

Methode 1: KRL Editor im Browser (empfohlen)

Der kostenlose KRL Editor öffnet .src und .dat Dateien direkt im Browser mit vollständigem Syntax-Highlighting und Code-Completion.

  • Beide Dateien gleichzeitig als Tabs geöffnet
  • Variablen aus der .dat werden in der .src als Completion angeboten
  • F12 springt von der Verwendung zur Deklaration

Methode 2: Notepad++ mit KRL-Plugin

Eine bekannte, aber nicht mehr gewartete Lösung. Syntax Highlighting vorhanden, aber keine Code-Completion oder Cross-File Navigation.

Methode 3: Visual Studio Code

Allgemeiner Editor ohne KRL-Unterstützung. Geeignet nur für einfache Textbearbeitung.

Dateiliste sortieren — automatisch

Der KRL Editor sortiert die DAT-Datei automatisch nach Typ (E6POS → REAL → INT → BOOL) und Name, mit natürlicher Zahlensortierung (P1, P2, P10 statt P1, P10, P2).
