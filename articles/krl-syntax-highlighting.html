KRL Syntax Highlighting — A Complete Guide

Syntax highlighting transforms plain KRL code into a visually organized, color-coded representation that makes programs easier to read, debug, and maintain. Here is everything you need to know about KRL syntax highlighting.

What KRL Syntax Highlighting Covers

Motion Commands

The core of any KRL program — motion commands are typically highlighted in blue:

PTP  LIN  CIRC  SLIN  SPTP  SCIRC

Control Structures

Program flow keywords stand out clearly:

IF bCondition THEN
   PTP P1
ELSE
   PTP P2
ENDIF

FOR i = 1 TO 10
   rArray[i] = 0.0
ENDFOR

Data Types and Declarations

Type keywords are colored differently from variable names:

DECL E6POS pHome
DECL REAL  rSpeed = 0.5
DECL BOOL  bReady = FALSE

System Variables

KUKA system variables starting with $ are specially highlighted:

$TOOL    = TOOL_DATA[1]
$BASE    = BASE_DATA[1]
$VEL.CP = 0.3
$OUT[1] = TRUE

FOLD Blocks

FOLD/ENDFOLD blocks collapse inline forms and can be shown collapsed or expanded:

;FOLD PTP HOME Vel=100% PDAT1 Tool[1] Base[0]
   PTP XPHOME
;ENDFOLD

Why Syntax Highlighting Reduces Errors

  • Typos in keywords are immediately visible (wrong color)
  • Missing ENDIF/ENDFOR — structural imbalance is visually obvious
  • Wrong variable types — color differences help spot type mismatches
  • Comments vs code — clearly separated
