# Release Notes — KUKA KRL Editor

## v1.0.0 — Free KUKA KRL Editor

**KUKA KRL Editor** is a free browser-based editor for KUKA Robot Language programs. It is intended for robot programmers, KUKA integrators, automation companies, schools and engineers who work with `.src`, `.dat`, `.sub`, WorkVisual projects and robot archives.

### Highlights

- Free KUKA Robot Language editor
- Browser-based usage via https://cnc-technik.de/kuka
- Syntax highlighting for KRL source and data files
- Code completion for KRL keywords, variables and functions
- Go to Definition for declarations across open files
- Multi-tab editing for `.src` and `.dat` files
- WorkVisual `.wvs` and `.wvps` project support
- Robot archive `.zip` support
- KRL tools for arrays, position mirroring, data list sorting and program splitting
- Community library for sharing KRL examples
