## English

### Free KUKA KRL Editor for Windows

A professional, browser-based editor for **KUKA Robot Language (KRL)** — free, no installation required, works directly in your browser.

### ✨ Features

| Feature | Description |
|---|---|
| **Syntax Highlighting** | Full KRL syntax coloring — keywords, positions, variables, folds |
| **Code Completion** | IntelliSense for all KRL keywords, variables and functions |
| **Go to Definition** | F12 jumps to variable/function declaration — cross-file |
| **Active Environment** | Load a robot archive as project context for all open files |
| **WorkVisual Support** | Open `.wvs` and `.wvps` project files directly |
| **Object Browser** | Lists all functions, variables and positions in the sidebar |
| **KRL Array Assistant** | Dialog to generate array declarations with initialization |
| **Mirror Positions** | Mirror all positions along YZ/XZ/XY plane |
| **Sort Data List** | Sort DECL entries by type and name (natural sort) |
| **Split Program** | Split large programs into sub-programs |
| **6 Program Types** | Standard, Function, Submit, Interrupt, Cell, Global |
| **Community Library** | Upload and download KRL programs with a points system |
| **Multi-Tab** | Work with multiple `.src` / `.dat` files simultaneously |
| **Archive Support** | Open and save Robot Archives (`.zip`, `.wvs`, `.wvps`) |
| **Dark / Light Theme** | Switchable editor theme |
| **Analytics** | Built-in usage statistics |
